# 九宮格中文輸入法（T9 Chinese IME）

給**九宮格實體鍵盤**（0-9、*、#）Android 手機用的中文輸入法，支援 Android 5.0（API 21）或以上。

支援的輸入方式：

| 模式 | 說明 |
|---|---|
| 粵 粵拼 | T9 式粵拼，每個字母按一下，自動猜字及詞語（例：你好 = `634468`） |
| 倉 倉頡 | 倉頡五代。字根按其英文字母所在的鍵（T9 自動猜字），亦可改用「多按」逐個字根輸入 |
| 速 速成 | 倉頡首尾碼 |
| 筆 筆畫 | 1 橫、2 豎、3 撇、4 點、5 折、6 萬用 |
| 自 自訂碼表 | 由你提供的數字碼表（例如九方），見下文 |
| Abc / abc / ABC | 英文多按輸入 |
| 123 | 數字 |

## 安裝

1. 從 [Releases](https://github.com/duxing0626/t9-chinese-ime/releases/latest) 下載 `T9ChineseIME.apk`，複製到手機並安裝（需要在「設定 → 安全」開啟「不明來源」）。
2. 開啟「九宮格中文輸入」app：
   - 按「1. 在系統設定中啟用本輸入法」，勾選本輸入法；
   - 按「2. 切換到本輸入法」。
3. 不想要的模式可以在設定中取消，讓 # 切換更快。

亦可用電腦安裝：`adb install -r T9ChineseIME.apk`

## 按鍵

| 按鍵 | 作用 |
|---|---|
| `#` | 切換輸入模式 |
| 長按 `#` | 系統輸入法選單 |
| `*` | 符號及表情符號（按 1-9 選，0 下一頁；在符號表中再按 `*` 下一類、`#` 上一類） |
| 長按 `*` | 打開本輸入法設定 |
| `0` / OK | 選第一個（或反白的）候選字 |
| ◀ ▶ | 移動反白 |
| ▼ | 進入「數字選字」：1-9 直接選字，0 下一頁，▲ 返回 |
| 刪除 / 返回 | 刪除一碼；沒有輸入時照常運作 |
| 長按數字 | 直接輸入該數字 |
| 沒有輸入時 `0` | 空格 |
| 沒有輸入時 `1` | 符號表（粵拼／倉頡／速成模式） |

出字後會顯示**聯想詞**，按 ▼ 再按數字即可選；按其他鍵會自動關閉。

### 自動調頻

你選過的字詞會記住：下次打**同樣的按鍵**時，它會排第一（例如 `64` 選過「唔好」，之後 `64` 第一個就是唔好）。
粵拼分段選出的詞語（例如先選「我哋」再選「去」）會自動加入詞庫，下次可一次過打出。
記錄只存在手機內，可在設定「清除學習記錄」。

### 表情符號（emoji）

- **候選中**：打「開心」「哈哈」「喊」「多謝」「生日」「貓」等字詞時，候選列會在該詞後面加上 😄 😂 😭 🙏 🎂 🐱。可在設定關閉。
- **符號表**：按 `*` 開符號表，再按 `*` 依次切換：中文標點 → 英文符號 → 最近使用 → 表情 → 人物 → 動植物 → 食物 → 地方 → 活動 → 物件 → 符號 → 旗幟。

只收錄 Android 5.0 字型能顯示的 emoji（約 730 個），較新的 emoji 在這部手機上只會顯示成空格，所以沒有加入。

### 粵拼

```
2 abc  3 def  4 ghi  5 jkl  6 mno  7 pqrs  8 tuv  9 wxyz   1 = 音節分隔
```

例：`唔該` = `6464`、`多謝` = `3693`。可以整句連打，再逐段選字（先選「你好」，剩下的碼繼續選）。

- **聲母簡拼**：每個字只打第一個字母，例：唔該 m g = `64`、多謝 d z = `39`。
- **懶音**：n 讀 l（你 = lei）、省略 ng（我 = o、五 = m）、gwo 讀 go（廣 = gong）都打得出；正音會顯示在候選列上方。三種懶音可在設定分別關閉。

### 倉頡／速成

```
2 日月金    3 木水火    4 土竹戈
5 十大中    6 一弓人    7 心手口尸
8 廿山女    9 田難卜重  1 = 萬用字根
```

例：倉頡「你」人弓火 = `663`；速成「好」女木 = `83`。候選列上方會顯示反白字的倉頡碼，方便確認。
如果覺得猜字太多重碼，可在設定開啟「倉頡／速成用多按輸入字根」：例如 `2` 按一下 = 日、兩下 = 月、三下 = 金。

### 自訂碼表（九方等）

九方輸入法是商業產品，碼表不能隨本程式附上。如果你有合法的碼表，可以轉成以下格式並放在手機
`/sdcard/T9IME/custom.txt`（UTF-8）：

```
#name=九方
1234	字
1234	宇	500
```

每行：數字碼、Tab（或空格）、字，以及可選的頻率數字（越大越前）。沒有頻率時，越前的行排越前。
放好檔案後，# 切換便會出現此模式。

## 疑難排解

- **按鍵沒反應／錯位**：在設定中打開「按鍵測試」，看看每個鍵送出的鍵碼。本輸入法使用標準的
  `KEYCODE_0`-`KEYCODE_9`、`STAR`、`POUND`、`DPAD_*`、`DEL`/`CLEAR`/`BACK`。如手機用了特別的鍵碼，把測試結果告訴我即可加上。
- **數字欄、電話欄**：本輸入法會讓 app 自己處理按鍵，不會出中文。
- **密碼、電郵、網址欄**：自動用英文 abc。

## 自行編譯

需要 JDK 17 或以上、Python 3、curl、unzip，不需要 Android Studio / Gradle（macOS 或 Linux）：

```bash
./tools/build.sh              # 輸出 dist/T9ChineseIME.apk
```

第一次執行會自動下載 Android build-tools 36 及 API 30 的 `android.jar` 到 `.sdk/`（約 300 MB，`tools/fetch_sdk.sh`）。

`app/assets/` 內的字典表已經生成好。如要由原始字典重新生成：

```bash
./tools/fetch_data.sh         # 下載固定版本的原始字典到 data/raw/
python3 tools/build_data.py   # 生成 app/assets/*.txt
```

第一次編譯會在 `tools/release.keystore` 建立簽名金鑰（不會上傳到 git）。**請備份這個檔案**：
日後的更新版必須用同一個金鑰簽名，才可以直接覆蓋安裝。
