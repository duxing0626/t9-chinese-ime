The lookup tables in `app/assets/` are generated by `tools/build_data.py` from the
sources below and remain under their original licenses (full texts in `licenses/`).

| Asset | Source | License |
|---|---|---|
| `jyutping.txt`, `jyutping_abbr.txt`, `assoc.txt`; character frequencies used by all tables | [rime-cantonese](https://github.com/rime/rime-cantonese) by CanCLID (`essay-cantonese.txt`, `jyut6ping3.chars/words/phrase.dict.yaml`) | CC BY 4.0 |
| `cangjie.txt`, `quick.txt` | [Jackchows/Cangjie5](https://github.com/Jackchows/Cangjie5) (`Cangjie5_HK.txt`) | MIT |
| `stroke.txt` | [rime-stroke](https://github.com/rime/rime-stroke) (`stroke.dict.yaml`) | LGPL-3.0 |
| `emoji_words.txt`, `emoji_groups.txt` | Unicode [emoji-test.txt](https://unicode.org/Public/18.0.0/emoji/) and [CLDR](https://github.com/unicode-org/cldr) annotations (`yue`, `zh_Hant`) | Unicode License v3 |

Changes made to the sources: readings converted to T9 digit keys, tones removed, characters
outside Big5-HKSCS/the corpus dropped, entries re-ranked by corpus frequency, lazy-pronunciation
and initials-only variants added, a small curated set of Cantonese emoji keywords added.
The exact versions used are pinned in `tools/fetch_data.sh`.

九方 (Jiufang) is a commercial input method; its code table is not included. Users can load a
table they are entitled to use via `/sdcard/T9IME/custom.txt`.
